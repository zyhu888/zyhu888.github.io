# Zeyu Hu — Personal Academic Website

This repository hosts my personal academic website:

**[https://zyhu888.github.io](https://zyhu888.github.io)**

I am a Ph.D. candidate in Statistics at the University of Connecticut. My research focuses on statistical methods for complex networks and high-dimensional data, particularly covariate-informed clustering, Bayesian modeling, and MCMC computation. My applied work spans biomedical research, epidemiology, public health, and pediatric clinical trials.

## Website Sections

- **Home** — Research interests, academic background, and contact information
- **Experience** — Industry, research, leadership, and service experience
- **Publications** — Preprints and peer-reviewed journal articles
- **Software** — Research software and R packages
- **About** — Additional information

## Repository Structure

- `pages/` — Source HTML pages for the website
- `assets/` — Styles, scripts, images, logos, and the current resume source file
- `papers/` — Publication PDFs
- `.github/workflows/deploy-pages.yml` — Publishes the organized source files while preserving the existing public URLs
